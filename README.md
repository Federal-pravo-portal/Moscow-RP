# -Moscow-RP
Правовой портал — единая информационная система законодательства проекта Moscow RP, предназначенная для удобного ознакомления с действующими нормативными правовыми актами. Здесь собраны Конституция, кодексы, федеральные законы, указы, постановления и иные документы, регулирующие общественные и государственные отношения в рамках игрового мира.
